# 看板 (dash) — 页面级覆盖

> **PROJECT:** COK 控制台
> **覆盖** `design-system/cok/MASTER.md`；未列出的规则一律按 Master 执行。
> **落地:** `cok/resources/cok_webui.html` 的 `#paneDash`

---

## 页面定位

**只读监控页。** 回答两个问题：*现在有什么该做的* 和 *账号现在什么状态*。
这里不放任何写操作按钮 —— 要动手就去"功能"页，或者从概览数字直接跳过去。

---

## 布局

| 区域 | 规则 |
|------|------|
| 首屏 | 概览数字块 `.ovbar`（**6 个主项常驻**：待办/体力/保护罩/队列/签到/自动打怪） |
| 次级指标 | 其余 4 项（任务奖励/福利/港口/查玩家）收进 `#ovMoreBtn`「更多」，点开才显示 |
| 概览 | 两列 `.grid.g2`，`多账号总览` / `今日待办` / `任务达成统计` 占满整行 `.span2` |
| 监控 | 三列 `.grid.g3`，每张监控卡可折叠 |
| 事件 | 日志区 `.logs` 固定 280px 高（可用"高度"按钮切换），过滤条 `.logbar` 吸在日志上方 |

- 概览数字块是**数字优先**的：标签 `--fs-xs`，数字 `--fs-3xl`（21px）+ `tabular-nums`，
  点数字直达能处理它的功能
- 「更多」按钮两态都要可见（它是展开态的唯一入口）：折叠时文案「更多 ▼」，
  展开后变成整行的「收起 ▲」。注意它**不能**带 `.ovMore` 类，否则被 `display:none` 干掉。
- 数字块状态色：待办>3 红、1–3 橙、0 绿；有待办时整块描蓝边（`.act`）引导先处理
- 内容上限 `max-width: 1560px`，超宽屏不要无限拉伸

## 本页专属规则

- **实时性要诚实**：连接状态在侧栏底部常驻，服务器日期/金币/刷新时间三项一直可见
- **事件流不许隐藏错误**：异常、警告必须能被过滤出来看到，不能被"全部"默认视图淹没
- **数字块不能是死链接**：每个 `.ov` 都要能 `goTo()` 到对应卡片
- **今日待办卡**每行右侧给一个直达按钮（去签到 / 去领取 / 去加速），不要只让用户自己找
- 折叠状态存 localStorage；用 `F` 键可以折叠/展开**当前可见 Tab** 的全部卡片
